# BioSeq-Basic
Analizador básico de secuencias de ADN en Python

## Descripción del proyecto

BioSeq Basic es una herramienta bioinformática desarrollada en Python para realizar el análisis básico de secuencias de ADN.

El proyecto se desarrolla como parte de la Actividad 1 de la asignatura Introducción a la Programación Científica de la Maestría en Bioinformática de la Universidad Internacional de La Rioja (UNIR).

## Propósito

Aplicar los fundamentos de la programación científica mediante el desarrollo colaborativo de una herramienta sencilla de análisis de secuencias de ADN, utilizando Git y GitHub como sistemas de control de versiones.

## Objetivo general

Desarrollar un programa en Python que permita analizar las características básicas de una secuencia de ADN.

## Objetivos específicos

- Introducir secuencias de ADN mediante la terminal.
- Determinar la longitud de una secuencia.
- Contabilizar los nucleótidos de adenina, timina, citosina y guanina.
- Calcular los porcentajes de contenido GC y AT.
- Validar las secuencias de ADN introducidas.
- Aplicar el control de versiones y el trabajo colaborativo mediante Git y GitHub.

## Requisitos

- Python 3.
- Git.
- Git Bash o una terminal compatible.

El programa no requiere la instalación de bibliotecas externas.

## Instrucciones de ejecución

1. Clonar el repositorio de GitHub.
2. Acceder a la carpeta BioSeq-Basic desde la terminal.
3. Ejecutar el siguiente comando:

```bash
python src/bioseq.py
```

4. Introducir una secuencia de ADN cuando el programa lo solicite.
